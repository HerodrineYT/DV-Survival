# DVSurvival 0.9.16

- С DVSeasons 0.3.13 температура уже учитывает погоду и время суток; Survival больше не прибавляет эти поправки повторно.
- При активной модели зимних стёкол показатель воздуха в кабине использует её температуру для того же локомотива. Температура самого стекла отличается от воздуха из-за теплообмена с улицей и отопителем.
- Перерисована иконка сытости: отдельные, читаемые вилка и ложка.
- Работа без Seasons и совместимость с прежним температурным API сохранены.

Сборка и автоматические тесты пройдены. Внешний вид интерфейса проверен по сгенерированному изображению; полный игровой прогон не выполнялся.
