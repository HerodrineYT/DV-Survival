# Survival Needs 0.9.15

Управление отопителями совместно с Dynamic Seasons 0.3.12 передано Seasons. Survival читает подтверждённое состояние конкретного локомотива для расчёта температуры кабины и самочувствия игрока. Повторные переключатели не создаются, старые сетевые и сохранённые настройки Survival не сбрасывают отопитель Seasons. Без Seasons остаётся прежняя самостоятельная система.

Проверено: сборка и 290 тестов. Интеграция температуры сохраняет поля `Main.runtime`, `SeasonRuntime.CurrentState`, `SeasonState.TemperatureCelsius` и `Current`; новый необязательный интерфейс использует `CabHeating.IsActive`, `Ensure`, `GetLevel`, `GetLevelById`. Обязательной зависимости от Seasons нет.
