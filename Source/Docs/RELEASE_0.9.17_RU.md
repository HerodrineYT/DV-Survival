# DVSurvival 0.9.17 — сон без перемотки в MP

Исправлен случай, когда штатный сон в MP не восстанавливал показатель «Сон»: при отключённом MP-продвижении времени нет календарного скачка, которого ожидала прежняя проверка. Теперь хост отдельно подтверждает личный сон в этом режиме по настройке MP, близости игрока к кровати и длительности. Общие часы и состояния остальных игроков не перематываются. При обычных настройках 10 часов сна восстанавливают показатель до 100%; полноценный сон от 8 часов снимает недосып и искажение спидометра, любой успешный сон сбрасывает толерантность к кофе.

Источник сна определяется непосредственно в штатном SleepCoro, в месте вызова TimeAdvance, без анализа стека и зависимости от таймера анимации. Быстрое перемещение и сетевые повторы времени не считаются личным сном. При настоящей перемотке сохранена прежняя сверка календаря. Локальное штатное использование кровати не отклоняется из-за задержки кэша объектов; удалённые игроки по-прежнему проходят проверку близости на хосте. В журнал добавлены причины отклонения и подтверждения сна.

Протокол 17: всем игрокам нужна DVSurvival 0.9.17. Формат сейва остаётся 1. Проверен API Multiplayer 0.1.16.0; MP остаётся необязательным. Обязательны Custom Item Mod 0.2.0 и Language Helper 1.2.1.

Обнаружено, что официальная UMM-лента MP отстаёт от опубликованного GitHub-релиза. Сборка теперь проверяет оба источника. Архив MP 0.1.16.0 проверен по опубликованному SHA256, его API совпадает с установленным. Сам установленный Multiplayer.dll отличается от архива; он не заменялся. Используемые API и обработчики сна проверены по обоим вариантам. Установленный Seasons 0.3.24 проверен только в части используемых температурных и отопительных API; Seasons не изменялся.

Проверки включают модульные тесты, сборку и проверку реального IL штатного SleepCoro. Живой тест сна с двумя игроками не выполнялся: после установки проверьте 10-часовой сон при отключённой перемотке, восстановление сна только у спящего и неизменность времени мира.
