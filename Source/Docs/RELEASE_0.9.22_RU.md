# DVSurvival 0.9.22

## Изменения

- Исправлен температурный урон при перегреве тела: урон начинается только выше 38,5 °C.
- Сохранён урон при температуре тела ниже 35 °C.
- Добавлен отдельный урон от температуры воздуха выше 55 °C.
- Урон рассчитывается авторитетно для каждого игрока и передаётся клиентам через MP-состояние.

Требования и совместимость указаны в основном руководстве мода.
