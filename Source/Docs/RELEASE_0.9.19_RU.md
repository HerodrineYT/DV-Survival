# DVSurvival 0.9.19 — проценты внутри колец

В стилях «Кольца» и «Латунь» цифровые значения четырёх потребностей перенесены внутрь окружностей: по центру под иконками. Положение самих колец, иконок, названий, температур и размер панели не изменены. Другие стили интерфейса не затронуты. Ползунок масштаба работает как прежде; новых операций в игровом цикле нет.

Проверены координаты производственного кода RU/EN и офлайн-превью. Сборка и автоматические тесты выполнены; офлайн-превью не является скриншотом игры.

Сохранены протокол 17, формат сейва 1 и исправления сна из 0.9.18. Проверены актуальные версии MP 0.1.16.0 (необязателен), Custom Item Mod 0.2.0 и Language Helper 1.2.1 (обязательны). Температурные/отопительные API установленного Seasons 0.3.28 повторно проверены; Seasons не менялся.
