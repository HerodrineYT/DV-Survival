# Проверка замечаний по производительности — 0.1.1

## Принятые изменения

1. Офисы: регистрация штатных AO-компонентов при OnEnable и учебного детектора при Awake. Загрузка сектора дополнительно проверяет только корни новой сцены, включая отключённые компоненты. Общий поиск оставлен при первом обращении и раз в 30 секунд вместо 3 секунд как страховка для уже загруженных/нестандартных объектов.
2. Топки: регистрация при Init, повторное использование списка; страховочный общий поиск раз в 30 секунд вместо 5 секунд. Неактивные объекты остаются в кэше для повторной активации, но тепла не дают. Уничтоженные ссылки удаляются. Порты топок читаются только в радиусе действия.
3. Кабина: три быстрые попытки с интервалом 3 секунды, затем редкая попытка через 30 секунд. Жёсткий вечный запрет после третьей попытки не введён: модифицированные кабины могут создавать управление позднее без замены объекта интерьера. Смена локомотива, интерьера, внешних объектов или SimulationFlow сбрасывает ожидание. Успешный поиск по-прежнему прекращает повторные сканирования.
4. CabinStatus: при измерении записываются только значения. Текст формируется при запросе настроек и повторно используется между GUI-событиями до нового измерения либо смены RU/EN.
5. README: актуальные имена архивов 0.1.1, MP 0.1.16.0 и протокол 21. Убрано устаревшее утверждение о фиксированной версии Dynamic Seasons 0.3.10; опциональная интеграция определяется доступным API. История изменений в README не возвращена.

## Что не менялось

- HUD, частота расчёта потребностей, сетевые интервалы, столкновения и физика игрока.
- Формулы тепла, границы помещений, радиус топки, поведение дверей и вентиляторов.
- Reflection-доступ к DVSeasons: при двух чтениях в секунду потенциальный выигрыш невелик, поэтому перестройка адаптера в этой задаче не оправдана.
- Номер версии 0.1.1, протокол 21 и формат сохранений.

## Проверка

- 416 тестов, включая ограничение частых повторных поисков, возможность позднего восстановления, отсутствие форматирования при 1000 измерениях без окна настроек и смену языка.
- Сборка и загрузка с MP и без него; проверены реальные методы, к которым подключается регистрация.
- Unity 2019.4: реальные игровые компоненты комнат и топок; отключённые компоненты, границы двух комнат, исключение домов, поворот/масштаб/смещение мира, новые объекты до страховочного поиска, регистрация без дублей, деактивация и повторная активация, удаление топок, радиус 7 м и открытие створок. Обработчик загрузки сектора проверен на отдельной тестовой сцене; это не полноценная поездка по миру.
- Лог Unity: artifacts/verification/climate-cache-unity.log. Автотест не измеряет FPS реальной игровой сессии. Утверждение об устранении падения с 70 до 40 FPS не делается.
